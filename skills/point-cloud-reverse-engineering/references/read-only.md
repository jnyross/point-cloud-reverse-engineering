# Read-only inquiry dispatcher

This is the only non-mutating route. Do not edit scans, models, contracts,
runtime configuration, or project files while using it. A request that asks to
compare, choose, select, or decide remains advisory even when it names Blender,
OCCT, browser, mesh-first, Linux, or desktop authorities.

## Dispatch

- For a failure, audit, explanation, recovery assessment, artifact inspection,
  or verification question, read
  [diagnose-and-verify.md](read-only/diagnose-and-verify.md).
- For a comparison, authority choice, stack recommendation, or proposed hybrid
  architecture, read [stack-selection.md](stack-selection.md). Stop after the
  recommendation, proposed contract, risks, and next scoped action.
- If the inquiry asks both why an existing route failed and whether to replace
  it, diagnose the current evidence first, then compare only the viable routes.
- If intent is ambiguous, identify the missing source, authority, deliverable,
  tolerance, or unit fact. Do not infer authorization to build or change.

## Read-only output contract

1. State the observed source type, unit status, authority, deliverable, and last
   verified checkpoint, marking unknowns explicitly.
2. Separate direct evidence from inference and recommendation.
3. For comparisons, apply one fixed decision matrix and explain disqualifying
   requirements before scoring convenience.
4. For audits, apply the relevant portions of the
   [shared evidence contract](shared/evidence-and-validation.md) without creating
   or repairing artifacts.
5. End with the smallest concrete scoped action that would resolve the decision
   or failure. Do not perform it from this route.
